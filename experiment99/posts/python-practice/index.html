Python Practice: a script that talks back

Python-Practice holds one program, script.py. You run it in a terminal and it has a short conversation with you.

What it does

  • It asks "Are you having a good day?" and answers "yes" with "Thats nice!" and "no" with "Im sorry about that".
  • It asks whether you had a good day yesterday, and replies differently to each answer.
  • If you did, it offers to do your math homework. Turn it down and it teases you for doing math the slow way.
  • Then it asks for a simple equation, like 5+5, and prints the result.

How it works

Every question uses input(), which waits for you to type something and press Enter. The answer is stored in a variable, and if statements check it against "yes" or "no" to pick the reply.

The math part is the most interesting piece:

user_input = input("enter a simple math equation like 5+5 ")

try:
    result = eval(user_input)
    print("The result is:", result)
except (SyntaxError, NameError, ZeroDivisionError) as e:
    print("Error in the expression:", e)

eval() treats whatever you typed as Python and works it out, so 5+5 becomes 10. The try/except block catches the three ways that can go wrong: typing something that isn't a valid expression, using a name Python doesn't know, or dividing by zero. Instead of crashing, the program prints the error and finishes.

What it practices

  • Reading input from the user
  • Branching with if and else
  • Handling errors with try and except
