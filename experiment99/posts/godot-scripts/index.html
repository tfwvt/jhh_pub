Starting a collection of Godot scripts

Godot-scripts is a new repository for "miscellaneous godot scripts": pieces of code written for the Godot game engine.

What Godot is

Godot is a free, open-source engine for making 2D and 3D games. Most of a Godot game's behavior lives in scripts, usually written in GDScript, a language that looks a lot like Python. A script attached to a character might move it when keys are pressed, make it jump, or check whether it touched an enemy.

What's there so far

The repository was created on April 15, 2026 and doesn't have any scripts in it yet. New ones will be written up here as they're added.
